# Квесты с контрольными метками (вариант 5)

Мобильное приложение для iPhone: игровые сценарии, загадки и подсказки, сканирование QR-меток на локациях, учёт баллов и времени прохождения.

## Стек

Проект написан на React Native (Expo SDK 58), это альтернатива нативному стеку, разрешённая заданием.

| Требование задания | Реализация |
|---|---|
| SwiftUI | React Native + Expo Router |
| MVVM | Модели (`src/models`), ViewModel-хуки (`src/viewmodels`), экраны (`src/app`) |
| SwiftData (реляционная БД) | SQLite (`expo-sqlite`): профиль, история прохождений, временные метки |
| Realm (нереляционная БД) | Хранилище документов на `expo-sqlite/kv-store` (`src/data/documentStore.ts`), потому что Realm недоступен в Expo Go |
| Брокер сообщений Combine | RxJS (`src/broker`) |
| Камера | `expo-camera` |

Целевая версия iOS: 26.6 (`expo-build-properties` в `app.json`).

## Как это работает

```
Сканер ──TagScanned──▶ Брокер ──▶ Валидатор (сверяет SHA-256 хэш со сценарием)
                                      │
                       TagAccepted / TagRejected
                                      ▼
                             Запись прогресса в БД ──ProgressUpdated──▶ Интерфейс
```

Приложение хранит только хэши ответов, поэтому коды меток нельзя подсмотреть в его данных.

## Запуск

1. Установите на iPhone приложение **Expo Go** из App Store.
2. Установите зависимости и запустите сервер разработки:
   ```bash
   npm install
   ```
   ```bash
   npx expo start
   ```
3. Отсканируйте QR-код из терминала камерой iPhone.

### В браузере

```bash
npx expo start --web
```

В браузере камера не используется: экран сканера показывает снимки меток (`assets/mock-tags`), и приложение распознаёт QR-код на выбранном снимке. Для SQLite в браузере нужны заголовки COOP/COEP, они заданы в `metro.config.js` и `app.json`.

## QR-метки

Откройте `tags/tags.html` в браузере и распечатайте страницу (или покажите метки на экране другого устройства). Для дома подходит сценарий «Домашний переполох».

Сценарии редактируются в `scripts/scenarios.source.json` (там коды меток в открытом виде). После изменений выполните:

```bash
npm run scenarios
```

Скрипт пересоздаст `src/data/scenarios.json` (с хэшами вместо кодов), `tags/tags.html` и снимки меток для сканера-заглушки (`assets/mock-tags`, `src/data/mockTags.ts`).

## Структура

- `src/app` — экраны (View): главный экран, сценарий, текущий этап, сканер.
- `src/viewmodels` — ViewModel экранов.
- `src/broker` — брокер сообщений, валидатор меток, запись прогресса.
- `src/store` — общее состояние (Zustand).
- `src/data` — SQLite, хранилище документов, репозитории.
- `src/models` — модели данных.
- `scripts` — подготовка сценариев и меток.
